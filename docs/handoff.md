## 2. Architecture Overview
Self-contained **Pretrained SD-VAE + Rectified Flow + Diffusion Forcing DiT** world model built cleanly on top of `stable_worldmodel` (`swm`):

- **Visual Tokenizer (`diffusion_wm/models/vae.py`):** `SDVAEWrapper` (`stabilityai/sd-vae-ft-mse`, frozen, 8× downsample → `4 × H/8 × W/8` scaled latents; e.g., `128×128 → 4×16×16`) + `TinyConvVAE` for fast offline unit tests.
- **Backbone (`diffusion_wm/models/dit.py`):** `SpatioTemporalDiT` with factorized spatial bidirectional attention + causal temporal attention + AdaLN-Zero timestep/action modulation (predicts velocity fields `v_vis` and optional `v_proprio`).
- **World Model & Planner Interface (`diffusion_wm/models/diffusion_wm.py`):** `DiffusionWorldModel` implementing `swm.solver.Costable`:
  - **Training:** `compute_loss` runs Diffusion Forcing per-frame flow-time sampling (`_sample_training_tau`, spreading context length across `1..min(history_size, seq_len-1)` and splitting future targets 50/50 parallel vs independent `tau`) with Rectified Flow interpolation `z_tau = (1 - tau) * eps + tau * z_clean`.
  - **Planning Inference:** `sample_ode_parallel` and `sample_ode_autoregressive` (Euler or Midpoint ODE), single-level gradient checkpointing (`grad_checkpoint_rollout=True`, `grad_checkpoint_blocks=False`), chunked `rollout_batch_size`, and `get_cost()`/`criterion()` minimizing latent MSE vs `goal_embed_0` + `proprio_cost_weight * MSE(goal_proprio_0)`.
- **Train / Eval / Demo / Viz Entrypoints:**
  - `diffusion_wm/train.py` & `diffusion_wm/data.py` & `diffusion_wm/utils.py`
  - `diffusion_wm/planning_eval.py` & `diffusion_wm/eval.py`
  - `diffusion_wm/visualize.py` (plots, dreams, per-episode rollout GIFs/storyboards)
  - `diffusion_wm/demo.py` (standalone `diffusion_wm_demo.html` + Jupyter `launch_live_demo` + stdin/stdout JSON `--serve` worker)
  - `scripts/download_datasets.sh`, `scripts/download_eval_trajs.sh`, `scripts/precompute_vae_latents.py`, `scripts/subset_h5.py`
  - `notebooks/kaggle_pusht.ipynb`, `notebooks/kaggle_antmaze.ipynb`

- **Eval Benchmark (`diffusion_wm/config/eval/pusht_gd.yaml`):**
  - Uses `assets/eval_trajs/pusht/goal_offset_25_midpush_val.pt` (`v[10:36]`, `len=26`, `25` env steps between start and target, generated by `scripts/download_eval_trajs.sh`).
  - Config: `rollout_mode: parallel`, `horizon: 5`, `receding_horizon: 2`, `action_block: 5`, `cost_last_n: 2`, `num_ode_steps: 4`, `proprio_cost_weight: 0.02`, `eval_budget: 45`, `GradientSolver(num_samples=32, n_steps=25, lr=0.1, seed=42)`.
  - **Latest Result (`Run 4`, 10 eval episodes):** **`30.0%` (`3/10`)** — solved `ep2` (`29` steps), `ep4` (`18` steps), `ep6` (`30` steps); `steps_to_success_success_only: 25.67`.
- **Important Push-T Eval Semantics (Verified in `stable_worldmodel/envs/pusht/env.py`):**
  - `PushT.step()` evaluates `terminated, distance = self.eval_state(self.goal_state, state)`.
  - Success is **`np.linalg.norm(goal_state[:4] - cur_state[:4]) < 20`** px (over `[agent_x, agent_y, block_x, block_y]` in `512×512`) **and `angle_diff < np.pi / 9` (`20°`)**.
  - The green T (`self.goal_pose`) is purely background rendering; the true target is the `Target Goal` frame (`self.goal_state`).
  - `ep0..ep9` in `goal_offset_25_midpush_val.pt` are 10 mid-push windows sampled across 5 underlying validation rollouts (`episode_idx` `0..4`).
